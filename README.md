# DesignCalc Android

Android wrapper app for [DesignCalc](https://github.com/devsodage7/designcalc) — machine design toolkit (cutting parameters, bearing life, key & shaft, tolerance stack-up).

## Download APK
Latest debug APK: https://github.com/devsodage7/designcalc/releases/tag/v1.0-android

## Build
1. Open folder in Android Studio.
2. Sync Gradle.
3. Run on device/emulator (minSdk 24).

## Stack
- Kotlin + AndroidX WebView
- Assets: web app (index.html, calc.js, app.js, styles.css)
